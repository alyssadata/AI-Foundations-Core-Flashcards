## Repository Purpose

This repository provides a lightweight retrieval layer that compresses larger AI Foundations concepts into stable **trigger → association** pairs for faster human and AI reference.

Flashcards point to source material. They do **not** replace, redefine, or become canon.

---

## Structure

Each trigger has one Markdown file at the repository root. Files are named by trigger and sort alphabetically.

Each card uses the same minimal form:

```text
FRONT
Trigger

BACK
Smallest sufficient association.

SOURCE
Source layer / Source item

TYPE
concept
```

**One card = one retrieval trigger.**

The back should stay small enough to activate the correct concept without reproducing the full source definition.

---

## Retrieval Rule

**Trigger → association → source.**

Use the flashcard first for fast orientation. Follow the source when the full definition, distinction, boundary, or reasoning is needed.

---

## Authority Boundary

Cards sourced to **LOCKED CANON** are retrieval aids only.

**alyssadata/AI-FOUNDATIONS-LOCKED-CANON**
